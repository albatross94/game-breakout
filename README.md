# Breakout (벽돌깨기)

A classic Breakout/Arkanoid-style brick-breaking game, built with vanilla HTML5 Canvas and JavaScript — no build step, no dependencies.

## Features

- Paddle-and-ball physics with brick collision detection
- Score and lives tracked in a live HUD
- Keyboard and mouse controls
- Game-over / win overlay with restart

## Controls

- **Arrow Left / Arrow Right** — move the paddle
- **Mouse move** — move the paddle by following the cursor

## Usage

Just open `index.html` in a browser — no installation or server required.

```bash
open index.html   # macOS
start index.html  # Windows
```

## Tech

Plain HTML, CSS, and JavaScript rendered on a single `<canvas>` element in one file.
